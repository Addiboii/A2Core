# Quest documentation

- **[AUDIT_DEFERRED.md](./AUDIT_DEFERRED.md)** — quests not fixable without new exports (Abyss, events).
- **[AUDIT.md](./AUDIT.md)** — generated table (`python tools/audit_quests.py`): internal cross-checks, starter-bug fixes, and rows with data issues or public reference links.
- **[RESEARCH.md](./RESEARCH.md)** — how quest data is exported and which third-party sources we use for manual comparison.

Regenerate the audit after changing `tools/data/quests.json` or world spawn JSON.
