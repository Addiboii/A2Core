# Global patch — Oct 27 (PDT) / Oct 28 (CET) 2026

Summary of the **Steam/PURPLE Global** maintenance patch. Not assumed to apply to KR/TW unless NC publishes the same notes there.

## Official

- [NCSoft notice — Patch Notes \| Oct. 27 (PDT) / Oct. 28 (CET)](https://aion2.plaync.com/en-us/board/update/view?articleId=6ae19668577e8c01355e0210)
- Full text (no login): `https://api-global-community.plaync.com/aion2_global/board/update_en/article/6ae19668577e8c01355e0210`. Every row below was checked against this text; the earlier community-mirror values that differed were corrected (see "Corrected against the official text").

## Class / survivability

| Class | Level 45 base HP (before → after) |
| --- | --- |
| Gladiator, Templar | 4,702 → 6,202 (+1,500) |
| Assassin, Ranger, Sorcerer, Spiritmaster, Chanter, Cleric | 4,702 → 5,702 (+1,000) |

**Assassin-only skill changes**

- **Illusive Clone** — base cooldown 90s → 60s.
- **Heightened Sixth Sense** — HP effect values 1,000 / 2,000 / 4,000 at skill levels 5 / 10 / 20.

## Corrected against the official text

- Krao Cave and Draupnir Hard do **not** get a 2,600 gate; only the new Urugugu Canyon and Vakron Sky Island (Bakron Island) Hard modes ask 2,700. The 2,600 came from a mirror and was removed.
- The 4-minute Frenzy timer and the 3-revive limit belong to the **new** Urugugu/Vakron Hard modes. Whether the old Hard raids also get the revive limit is not stated (INFERRED yes; the Oct 28 client's Dungeon.dat marks them too).
- Wind Breeze: Odyle Energy (Bound) is 4/character/week plus 16/server/week; the 20/character item is removed; Instant Clear Ticket: Nightmare is new (14/server/week, 30,000 Kina) and Daily Dungeon's ticket limit changes to 14/server/week at 30,000 Kina; the 7-day Lower Abyss Rift Stone sale ends.
- Idle return to lobby is 3 h to 30 min (was written as unknown).
- Rows added that the mirrors did not carry: Daeva Pass Prelude to Flight (EXP table), Supply Requests (Sweet Balaur Berry) removal, the Hard retry resurrection-count fix, Hero/Odylium details.
